# Life Locker 🔒

A personal life-admin hub I'm building to keep tasks, bills, expenses and recommendations in one place, using AI to help.

> The app's code and data are private. This repo is the public story of building it: notes, roadmap and lessons I'll use in my workshops.

## Built with
- React (Vite)
- Netlify + Netlify Functions
- Claude (Anthropic) for AI features

## What's working so far
- ✅ Tasks
- ✅ Bills, including subscription and payment fields
- ✅ Expenses, with editing
- 🚧 Recommendations with AI assist
- 🚧 Voice input

## Roadmap
- Dashboard overview
- Reminders for upcoming bills
- A workshop-ready starter template
